GREENHILLS DAYCARE - EMAIL VERIFIED PASSWORD RESET

WHAT CHANGED
- Forgot Password now uses a two-step process.
- Step 1 checks Role + Username + Email Address.
- A random 6-digit code is generated and sent to the account email.
- Step 2 requires that code before the new password can be saved.
- Verification codes expire after 10 minutes.
- Only a hash of the code is stored in Supabase.
- Direct password reset through the old UI path has been disabled.

SUPABASE SETUP
1. Open Supabase SQL Editor.
2. Run the complete SUPABASE_REGISTRATION_FIX.sql included in this ZIP.
3. This adds the reset fields and secure RPC functions.

EMAILJS SETUP (REQUIRED TO ACTUALLY SEND EMAIL)
1. Create an account at EmailJS.
2. Add/connect the email service you want to use.
3. Create an email template.
4. The template should use these variables:
   {{to_email}}
   {{username}}
   {{verification_code}}
   {{expires_minutes}}
   {{app_name}}
5. Copy your EmailJS Public Key, Service ID, and Template ID.
6. Open email-config.js and replace:
   YOUR_EMAILJS_PUBLIC_KEY
   YOUR_EMAILJS_SERVICE_ID
   YOUR_EMAILJS_TEMPLATE_ID
7. Upload the updated files to your hosting/server.

IMPORTANT
This project currently uses a custom public.users login with plaintext passwords.
The password reset flow is improved with email verification, but the existing
authentication architecture is not equivalent to Supabase Auth. For production,
migrate login/password storage to Supabase Auth and use Supabase's built-in
password recovery.

TEST
- Open Login.
- Click Forgot Password.
- Select the correct role and enter username + account email.
- Click Send Verification Code.
- Confirm the email arrives.
- Enter the 6-digit code and a new password.
- Try logging in with the new password.
- Try an incorrect/expired code; the password must not change.
